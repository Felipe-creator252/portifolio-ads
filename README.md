## 📚 1. Boletim Escolar Automático (Web & Python)
Uma ferramenta interativa desenvolvida para gerenciar notas escolares, calcular médias ponderadas trimestrais e projetar metas para o último trimestre.

* **O que faz:** 
  * Lê e processa notas de um arquivo estruturado (`notas.json`).
  * Escolhe automaticamente a maior nota entre a avaliação regular e a EAC (Estudo de Acompanhamento e Recuperação) de cada trimestre.
  * Calcula a média ponderada final do ano ($T1 \times 3 + T2 \times 3 + T3 \times 4 / 10$) e dá o veredito de aprovação ou recuperação.
  * Caso o terceiro trimestre ainda não tenha ocorrido, calcula dinamicamente a meta exata que o aluno precisa atingir para passar de ano.
* **Tecnologias:** HTML5, CSS3, JavaScript (e versão complementar em Python).

## 🖨️️ 2. Calculadora de Impressão 3D
Uma aplicação voltada para o cálculo preciso de custos e orçamentos para impressão 3D.

* **O que faz:**
  * Estima custos de materiais (filamentos/resina), consumo elétrico, tempo de máquina e margens de lucro.
  * Permite múltiplos modelos de precificação e leitura de parâmetros para facilitar a rotina de quem trabalha com fabricação aditiva.
* **Tecnologias:** HTML, CSS e JavaScript.

## 🛒 3. Site de Pedidos (Explorador)
Um sistema web voltado para organização e gerenciamento de pedidos de forma ágil e intuitiva.

* **O que faz:**

## 🛠️ Como Executar os Projetos
Como são projetos baseados em tecnologias web front-end (HTML/CSS/JS) e arquivos JSON locais:
1. Faça o clone ou o download deste repositório na sua máquina.
2. Abra a pasta do projeto desejado no seu editor de código (como o VS Code).
3. Utilize uma extensão como o **Live Server** para abrir o arquivo `index.html` diretamente no seu navegador, ou dê um duplo clique nele.
